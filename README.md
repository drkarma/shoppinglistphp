# 🍄 Svampar och trädslag – vilka passar ihop (inkl. klimat i Sverige)

**Symbolförklaring:**
- ⭐ = Bäst  
- ✔️ = Lämplig  
- ❌ = Rekommenderas ej  
- (blankt) = Okänt / ej testat  
> För de flesta svampar bör barrträd eller mjuka träslag undvikas.

**Klimatnyckel:**
- 🇸🇪✅ = Går att odla utomhus i Sverige  
- 🌿⚠️ = Kräver värme / växthus eller inomhusodling  
- 🧊❌ = För varmt klimat, ej lämplig i Sverige
